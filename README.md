# Buenos Aires: Noche Zombie

Juego web sin dependencias. Dos héroes inspirados en las fotos proporcionadas, seis oleadas y tres escenarios: Recoleta, Obelisco y Caminito. Los ataques apuntan al zombi más cercano. Los corazones recuperan vida; cambiar de oleada también recupera dos puntos.

## Ejecutar

```sh
cd /workspace/Halloween
python3 -m http.server 3000 --bind 0.0.0.0
```

Abrir el servidor desde el navegador. Para jugar en un teléfono de la misma red, usar la dirección IP del equipo y el puerto 3000; en un entorno remoto hace falta exponer el puerto mediante la plataforma.

- Mover: WASD o flechas; en celular, joystick izquierdo.
- Disparar: mantener Espacio o el botón MAGIA.
- Pausa: P, Escape o el botón superior.

No necesita cuentas, claves ni compilación. Las fuentes web son opcionales y tienen alternativas locales. Las fotos se sirven localmente.
